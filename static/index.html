Enablement Coach

Turns study notes into a short quiz, then scores it and explains each answer. This early version has one built-in topic.

Google Cloud Basics

Five questions, written by Gemini from a set of study notes. Writing them can take up to a minute.

How it works

  1. The server sends the study notes to Gemini on Google Cloud and asks for questions in a fixed format.
  2. Code checks every question: four different options, and the answer must be one of them. It tries again if too few pass.
  3. The answers stay on the server until you submit, and your score is worked out by code, not by the model.
  4. A daily limit on model calls keeps the running cost under control.
